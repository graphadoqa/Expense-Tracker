# Ansaf Expense Tracker

An iPhone-first, local-only expense / credit / invoice PWA.

## Included
- Home dashboard
- QAR + INR currency support
- Expenses with receipt photo attachment
- Search and history
- Credit given / credit bought
- Person-based payment history
- Credit statement PDF via browser Print → Save as PDF
- Invoice + quotation creator
- Invoice preview based on the supplied reference layout, simplified and branded as ANSAF
- Recurring-expense-ready settings area
- Backup/restore JSON
- CSV export
- PWA manifest

## Hosting
Upload all files in this folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, or ordinary web hosting).

No server/database is required for normal use. Data is stored in the browser on the iPhone.

## iPhone
Open the hosted URL in Safari → Share → Add to Home Screen.

## Important
Local browser storage is device/browser-specific. Use More → Backup & Restore regularly. Receipt photos are stored locally with the expense data.
